# Auctionary

> Auction house addon for World of Warcraft **3.3.5a (WotLK)** – a backport of modern Auctionator.

Shopping lists, selling, cancelling, price history and tooltips in the modern Auctionator style, rebuilt for the 3.3.5a client.

**Based on [Auctionator](https://github.com/Auctionator/Auctionator)** by Borjamacare and plusmouse (MIT licence).

## Features
- **Shopping** – search, shopping lists, buy view; typos are corrected when nothing is found
- **Selling** – click a bag item, check the suggested price, post; favourites and a green "good time to sell" dot
- **Cancelling** – shows your auctions and marks undercut ones
- **Full scan** with price history and averages
- **Tooltips** – vendor, auction, average, age, mats cost, disenchant, prospect, mill
- Runs alongside TradeSkillMaster and the old Auctionator 2.6.8

## Installation
1. Download the latest ZIP from **Releases**.
2. Copy the `Auctionary` folder into `World of Warcraft/Interface/AddOns/`.
3. Restart the game.

`/aury` lists all chat commands. See [README.txt](README.txt) for the full start guide.
